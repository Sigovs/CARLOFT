01How to ask for a change

Name the style, say what changes.

Each style below has a short name (H1, H2, Body text, Miami Blue…). Use that name and the new value. The change then applies everywhere the style is used, so the site stays consistent.

Text size

H2: smaller, 28px

Every section title gets smaller, on every section.

Text style

Body text: one size up

All running text on the page gets larger, from 17px to 18px.

Colour

Miami Blue: #0090D0

Buttons, section titles, the phone button and the logo change together.

Before a change goes live we check that text stays easy to read. If a value would make it hard to read, we say so and suggest the nearest one that works.

02Colour

One blue. Everything else lets the cars shine.

The site is dark so the cars carry the colour. Miami Blue is the only brand colour; the rest are the backgrounds and text colours that hold the page together. Click a colour code to copy it.
